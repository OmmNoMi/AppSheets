# AppSheet Pattern Library
This skill contains reference documents for various AppSheet patterns.
Because the pattern library is large, they are stored in the `references/` subdirectory.
To use this skill:
1. Use the `list_dir` tool to explore `.agents/skills/appsheet-patterns/references/`.
2. Use the `view_file` tool to read the specific markdown file for the pattern you need.
