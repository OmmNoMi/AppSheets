1. Executive Summary & Project Background

Following the comprehensive technical discovery session conducted on August 1, 2026 between Kayson Yang (Yangon Broom) and Nomeshwer Sharma (OmmNoMi Automation LLP), this document presents the formal commercial quotation and architectural transition strategy for Yangon Broom's operational software ecosystem.

Yangon Broom has previously invested approximately $1,000 USD with local freelance developers in building a custom React/TypeScript application hosted on AWS. Technical evaluation confirms that the current system suffers from inaccurate and incomplete data across cleaner contacts, client management, booking calendars, and subscriber records, creating development uncertainty and hindering long-term business scalability.

To prevent unnecessary capital expenditure on "re-inventing the wheel", OmmNoMi Automation LLP proposes migrating Yangon Broom's operations to the industry-standard, open-source Frappe Framework / ERPNext Ecosystem. Hosted on Frappe Cloud, this strategy unifies internal booking, CRM, HR/cleaner management, accounting, and customer ticketing into a single, fully autonomous digital infrastructure.

2. Discovery Audit & Technical Assessment
Current React / AWS Infrastructure Legacy Audit
  • Tech Stack: Single-page marketing site (Home/About), React front-end, TypeScript, AWS cloud infrastructure.
  • Current Expenses: ~$30/month ($100/yr web server + $10/mo ongoing maintenance fee).

  • Overarching Goal: Transition toward a fully automated ecosystem where clients book cleaners directly with zero manual intervention.

  • Operational Ownership: OmmNoMi handles end-to-end software, web presence, and optional remote operational data entry support.
3. Target Solution Architecture — Frappe Ecosystem

Rather than continuing custom development on an unproven codebase, OmmNoMi recommends deploying the Frappe Framework—a high-performance, Python-based open-source platform utilized globally by enterprise leaders such as Zerodha, Blinkit, and OneCard.

Application Module Primary Functionality & Business Scope Operational Impact
ERPNext Core Central operational management, multi-location support, customer lead capture, invoicing, and real-time financial reporting. Replaces fragmented Wix & custom sheets; unifies real-world business activities in one system.
Frappe HR Cleaner directory, employee onboarding, attendance tracking, shift scheduling, expense claims, and payroll processing. Provides structured management for cleaner staff and administrative team members.
Frappe CRM Customer relationship management, lead pipeline tracking, service inquiry capture, and automated follow-ups. Eliminates lost booking leads and establishes a structured sales/client acquisition pipeline.
Frappe Helpdesk Customer inquiry ticketing, cleaner issue reporting, feedback management, and SLA tracking. Centralizes post-booking support and operational feedback into a single dashboard.
4. Phased Implementation Roadmap

To ensure maximum cost efficiency and immediate operational value, development will follow a structured, phased rollout plan:

Phase 1: Internal Booking & Operations (Immediate) Phase 1 Focus
  • Deployment of Frappe Cloud infrastructure and baseline security configuration.
  • Setting up internal booking management, cleaner directory, and client database.
  • Integration of interactive calendar for manual data entry by existing team.
  • Configuration of Frappe HR (cleaners) & Frappe CRM (lead capture).
  • Staff onboarding on out-of-the-box Frappe Desk UI to avoid premature custom UI spending.
Phase 2: Customer Self-Service Portal (Future Stage) Phase 2 Stage
  • Public-facing client booking portal with direct cleaner scheduling.
  • Automated payment gateway integration and subscription management.
  • Multi-location timetables and customer self-management accounts.
  • Custom branded front-end UI built on top of Frappe REST APIs as business volume expands.

6. Frequently Asked Questions (Strategic Alignment)
Q: Why move to Frappe instead of repairing the existing React/AWS codebase?
A: Building custom ERP and CRM software from scratch is expensive and prone to maintenance debt. Frappe provides an enterprise-tested, open-source foundation used by companies like Zerodha and Blinkit. Moving to Frappe eliminates custom backend bugs while reducing ongoing server costs to a flat $25/month for unlimited users.
Q: How does the system handle multi-language support (Burmese & English)?
A: The Frappe Framework features built-in internationalization (i18n). Custom fields, forms, and user interfaces can be localized so internal staff can operate in Burmese or English seamlessly.
Q: What happens when Yangon Broom is ready for the customer-facing booking portal?
A: Because Frappe automatically exposes robust REST APIs for all data models, Phase 2 (customer self-booking portal) can be built directly on top of the Phase 1 backend without rearchitecting the database or losing historical booking data.
