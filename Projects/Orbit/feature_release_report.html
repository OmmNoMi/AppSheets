Executive Summary
This release note outlines the deployment of a native one-click export option in Orbit HRMS. Built directly within the existing Documents module, this utility allows authorized HR personnel to immediately generate and download employee visa and compliance metadata in standard CSV format, significantly optimizing organizational reporting timelines.
Context & Request
Rizalyn Bolasco from the BLR team requested a way to download employee document expiry dates directly from the Orbit app — needed for compliance and reporting purposes. We have built and delivered this as a native export action inside the existing Documents view, with full role-based access control so only U_People_Admin, U_People_Manager, U_People_User and U_People_Viewer can see and use it. All other roles have zero access.

Verification & Testing Steps
  • Log in to Orbit HRMS with a user mapped to one of the 4 allowed roles (e.g., U_People_Admin).
  • Navigate to the Documents module from the primary application menu.
  • Verify that the primary blue Export Documents action icon appears in the top navigation header.
  • Click the export action button. A native CSV document named Documents.csv will compile and download containing employee document metadata.
  • Log in with a user containing a role not specified above (e.g., general Employee) and confirm the export option is completely hidden.
Helpful FAQs
Where does the exported file save?
The file downloads instantly to your browser or system's local Downloads folder as a standard CSV format sheet.
Is the file compatible with Excel?
Yes. The export compiles as a standard .csv spreadsheet which opens natively in Microsoft Excel, Google Sheets, or Apple Numbers.
What if the export button isn't visible?
Verify that your mapped user profile is mapped to one of the 4 authorized U_People roles in your HR database.
Does exporting alter active documents?
No. The Export action acts strictly as a secure "read-only" mirror pull and has zero effect on active document status or data tables.
