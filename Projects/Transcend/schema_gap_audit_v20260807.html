⚠️ Critical HIPAA & PCI Security Notice
Raw 16-digit credit card numbers (CardNumber) and security codes (SecurityCode) are present in the Client and Payment AppSheet tables. Per DeploymentChecklist.md, these fields must be masked via Apps Script (extractLast4()) and hidden from non-admin roles (U_Operations_Manager) using column level Show_If and slice security filters.
